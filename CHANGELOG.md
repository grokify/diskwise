## [v0.1.0] - 2026-08-22

### Highlights

- First release: a full discovery pipeline from a prioritized concurrent filesystem scanner through a SQLite index, knowledge-aware detectors, and a fail-closed policy engine, surfaced through the `diskwise` CLI (`scan`, `hotspots`, `opportunities`, `savings`).
- `insights` package: a JSON intermediate representation an LLM agent can fill out with ranked, evidence-backed savings opportunities — including kept/redundant path pairs and per-tool reclaim actions — rendered deterministically to Markdown or HTML.
- `report` command: self-contained, sortable/filterable HTML and XLSX exports of reclaim opportunities, with no external script or CDN dependency.

### Added

- `platform`: macOS allocated size (st_blocks), device/inode, and per-volume capacity/mount detection ([`8f5fb0b`](https://github.com/grokify/diskwise/commit/8f5fb0b))
- `scan`: concurrent priority-queue directory walker (GOMAXPROCS workers, largest-known-bytes-first) with hard-link dedup and mount-boundary/depth handling ([`a08769d`](https://github.com/grokify/diskwise/commit/a08769d))
- `index`: SQLite index (modernc.org/sqlite, no cgo) with batched ingest, subtree byte rollups, and subtree-replacing rescan ([`ad572d9`](https://github.com/grokify/diskwise/commit/ad572d9))
- `entity`: core entity model (cache, archive, database, container, VM, artifact family, ...) for attributing bytes to meaningful things instead of raw paths ([`9df61e4`](https://github.com/grokify/diskwise/commit/9df61e4))
- `knowledge`: registry of known heavy-storage locations (Docker Desktop, Xcode, Homebrew, Go, Node, Python, AI models, iOS backups, browsers, Trash) ([`01824c9`](https://github.com/grokify/diskwise/commit/01824c9))
- `policy`: fail-closed action-class engine — managed data (databases, containers, VMs, apps) capped at backup_then_delete, safe_delete requires ≥0.8 confidence ([`7056ef7`](https://github.com/grokify/diskwise/commit/7056ef7))
- `detect`: KnownLocationDetector, ArchiveInstallerDetector, ArtifactFamilyDetector, and LargeUnexplainedDetector, each claiming disjoint territory so nothing is double-counted ([`495eda5`](https://github.com/grokify/diskwise/commit/495eda5))
- `rollup`: collapses a finding's covered paths to the smallest fully-covered directory set, decomposing partially covered ("mixed") directories instead of over-claiming them ([`76afd62`](https://github.com/grokify/diskwise/commit/76afd62))
- `service`: scan/rescan/summary/tree/largest/hotspots/opportunities/savings orchestration over the scanner, index, knowledge registry, detectors, policy engine, and rollup ([`7f6eb46`](https://github.com/grokify/diskwise/commit/7f6eb46))
- `report`: HTML (vendored sortable/filterable table, file:// links) and XLSX (frozen header, autofilter) exports of opportunities ([`90e0088`](https://github.com/grokify/diskwise/commit/90e0088))
- `insights`: JSON IR (`insights.Report`) for narrative savings write-ups, with a generated/embedded JSON Schema and deterministic Markdown/HTML renderers ([`eb6d7b6`](https://github.com/grokify/diskwise/commit/eb6d7b6))
- `diskwise` CLI: `scan`, `rescan`, `summary`, `tree`, `largest`, `hotspots`, `opportunities`, `savings`, `report`, and `insights` subcommands, with a live terminal progress meter during scan/rescan and `--json` output on every command ([`6cf2057`](https://github.com/grokify/diskwise/commit/6cf2057))
