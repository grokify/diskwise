## [v0.2.0] - 2026-10-07 ([`8740242`](https://github.com/grokify/diskwise/commit/8740242))

### Highlights

- Totals that add up and say how old they are: unexplained directories are disjoint with already-explained bytes subtracted, savings no longer counts the unknown tier, and results show when they were measured and flag findings whose paths have since been removed.
- New commands: `preflight` (free space for an upgrade), `pairs` (archives vs. extracted copies), `review` (checkbox worklist), and `export` (a consistent set of JSON files), with `--redact` / `--redact-prefix` to share output safely.
- First MkDocs user guide, deployed to GitHub Pages.

### Breaking

- `opportunities --json` now prints an object (`Root`, `ScannedAt`, `ScanStatus`, `Stale`, `Opportunities`, ...) instead of a bare array, matching `export`'s `opportunities.json`; `savings` no longer counts the keep and unknown tiers in its headline total ([`8740242`](https://github.com/grokify/diskwise/commit/8740242))

### Added

- `preflight` command: capacity, available space, APFS container free space and local snapshots against a `--need` requirement, exiting non-zero when short ([`b8b9195`](https://github.com/grokify/diskwise/commit/b8b9195))
- `pairs` command: compare archives with the same-named directory beside them by file count and bytes, comparing Photos library originals only ([`da4b6c3`](https://github.com/grokify/diskwise/commit/da4b6c3))
- `review` and `export` commands: a checkbox worklist grouped by tier, and savings/opportunities/hotspots/review files each recording their root; `--min-size` states what it omits ([`3b8d5ad`](https://github.com/grokify/diskwise/commit/3b8d5ad))
- `--redact` and `--redact-prefix` on opportunities, hotspots, savings, pairs, report, review and export ([`5e951c9`](https://github.com/grokify/diskwise/commit/5e951c9))
- Managed bundles (Photos, Music, TV, iMovie, Final Cut, Logic, GarageBand libraries, sparse bundles) reported as keep instead of unknown ([`4b4da9d`](https://github.com/grokify/diskwise/commit/4b4da9d))
- Results show when the covering scan finished, warn when it is over a week old, and mark findings whose paths no longer exist ([`8740242`](https://github.com/grokify/diskwise/commit/8740242))
- `scan` lists denied directories with Full Disk Access guidance ([`dac3878`](https://github.com/grokify/diskwise/commit/dac3878))

### Changed

- Unexplained directories are disjoint and exclude bytes other findings already report; savings reports a reclaimable total; hotspots prints known-location paths; commands defaulting to the current directory say so on stderr ([`a4f9bce`](https://github.com/grokify/diskwise/commit/a4f9bce))

### Fixed

- An archive beside a same-named directory is checked against it (plain tar and zip) instead of being called likely-safe on the name alone; plain `.tar` is now recognized as an archive ([`e55fc10`](https://github.com/grokify/diskwise/commit/e55fc10))

## [v0.1.0] - 2026-08-22 ([`d4a6115`](https://github.com/grokify/diskwise/commit/d4a6115))

### Highlights

- First release: a full discovery pipeline from a prioritized concurrent filesystem scanner through a SQLite index, knowledge-aware detectors, and a fail-closed policy engine, surfaced through the `diskwise` CLI (`scan`, `hotspots`, `opportunities`, `savings`).
- `insights` package: a JSON intermediate representation an LLM agent can fill out with ranked, evidence-backed savings opportunities — including kept/redundant path pairs and per-tool reclaim actions — rendered deterministically to Markdown or HTML.
- `report` command: self-contained, sortable/filterable HTML and XLSX exports of reclaim opportunities, with no external script or CDN dependency.

### Added

- `platform`: macOS allocated size (st_blocks), device/inode, and per-volume capacity/mount detection ([`eae7683`](https://github.com/grokify/diskwise/commit/eae7683))
- `scan`: concurrent priority-queue directory walker (GOMAXPROCS workers, largest-known-bytes-first) with hard-link dedup and mount-boundary/depth handling ([`153bb75`](https://github.com/grokify/diskwise/commit/153bb75))
- `index`: SQLite index (modernc.org/sqlite, no cgo) with batched ingest, subtree byte rollups, and subtree-replacing rescan ([`ce2c036`](https://github.com/grokify/diskwise/commit/ce2c036))
- `entity`: core entity model (cache, archive, database, container, VM, artifact family, ...) for attributing bytes to meaningful things instead of raw paths ([`251d184`](https://github.com/grokify/diskwise/commit/251d184))
- `knowledge`: registry of known heavy-storage locations (Docker Desktop, Xcode, Homebrew, Go, Node, Python, AI models, iOS backups, browsers, Trash) ([`da9cd8f`](https://github.com/grokify/diskwise/commit/da9cd8f))
- `policy`: fail-closed action-class engine — managed data (databases, containers, VMs, apps) capped at backup_then_delete, safe_delete requires ≥0.8 confidence ([`9638075`](https://github.com/grokify/diskwise/commit/9638075))
- `detect`: KnownLocationDetector, ArchiveInstallerDetector, ArtifactFamilyDetector, and LargeUnexplainedDetector, each claiming disjoint territory so nothing is double-counted ([`b2b3c8c`](https://github.com/grokify/diskwise/commit/b2b3c8c))
- `rollup`: collapses a finding's covered paths to the smallest fully-covered directory set, decomposing partially covered ("mixed") directories instead of over-claiming them ([`4b7f817`](https://github.com/grokify/diskwise/commit/4b7f817))
- `service`: scan/rescan/summary/tree/largest/hotspots/opportunities/savings orchestration over the scanner, index, knowledge registry, detectors, policy engine, and rollup ([`398a64b`](https://github.com/grokify/diskwise/commit/398a64b))
- `report`: HTML (vendored sortable/filterable table, file:// links) and XLSX (frozen header, autofilter) exports of opportunities ([`c7bc587`](https://github.com/grokify/diskwise/commit/c7bc587))
- `insights`: JSON IR (`insights.Report`) for narrative savings write-ups, with a generated/embedded JSON Schema and deterministic Markdown/HTML renderers ([`4a0a506`](https://github.com/grokify/diskwise/commit/4a0a506))
- `diskwise` CLI: `scan`, `rescan`, `summary`, `tree`, `largest`, `hotspots`, `opportunities`, `savings`, `report`, and `insights` subcommands, with a live terminal progress meter during scan/rescan and `--json` output on every command ([`e1489ec`](https://github.com/grokify/diskwise/commit/e1489ec))
